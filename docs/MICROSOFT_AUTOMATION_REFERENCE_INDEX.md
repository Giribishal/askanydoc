## Handling rule

Microsoft Learn pages should normally be stored as links and metadata. Downloaded PDFs must remain official, retain their source URL and retrieval date, and be uploaded only when Microsoft makes the download available for that purpose. This index itself is safe to store as a small SharePoint reference document.
