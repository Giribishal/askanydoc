# SharePoint document lifecycle automation

Classification: General
Official source: https://learn.microsoft.com/en-us/sharepoint/modern-experience-sharing-permissions

Use a SharePoint trigger for file creation or modification, validate file type and metadata, then route the item to approval, retention, notification, or an exception queue. Preserve the item ID and version in every downstream action. On failure, record the flow run and leave the source item unchanged until recovery is confirmed.
