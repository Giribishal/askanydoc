# Production flow monitoring and recovery runbook

Classification: Senior-Restricted
Official source: https://learn.microsoft.com/en-us/power-automate/failure-monitoring

Monitor failed runs, duration, throttling, connector errors, and recurrence. Classify each failure as data, permission, transient service, or design error. Retry only safe transient failures, notify the owner, and record the run ID, action, timestamp, and recovery result.
